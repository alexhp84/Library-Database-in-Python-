# Library Database in Python

A Python application for managing a library database, with a database layer (`db.py`) and an application entry point (`main.py`).

## Run
```bash
cd library_app
python main.py
```

## Structure
- `library_app/db.py`: database access and queries
- `library_app/main.py`: application logic
- `library_app/my_sql.db`: database file

## Skills
Python, SQL, database design
